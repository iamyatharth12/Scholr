# Scholr

Scholr is a modern platform that helps parents and students discover, compare, and evaluate nearby schools using structured, easy-to-understand data. It simplifies school selection by bringing key information like fees, facilities, and insights into one place.

---

## 🚀 Features

* 🔍 **Search & Filter** schools by board, fees, and location
* 📊 **Compare Schools** side-by-side for better decision-making
* ⭐ **Save Schools** to revisit later
* 📄 **Detailed School Pages** with structured information
* 📱 **Responsive Design** for mobile and desktop
* ⚡ **Fast & Clean UI** focused on usability

---

## 🧠 Why Scholr?

Most platforms only list basic details.

Scholr focuses on:

* Clear, structured data
* Better comparison tools
* Simpler decision-making

---

## 🛠 Tech Stack

* **Frontend:** HTML, CSS, JavaScript
* **Backend / Database:** Supabase
* **Hosting:** Vercel

---

## 📂 Project Structure

* `index.html` → Home page (search, filters, listings)
* `school.html` → School detail page
* `compare.html` → Comparison view
* `script.js` → Main logic
* `styles.css` → UI styling

## ⚙️ Setup

1. Clone the repo:

```bash
git clone https://github.com/your-username/scholr.git
```

2. Open the project folder:

```bash
cd scholr
```

3. Add your Supabase credentials:

```js
const supabaseUrl = "YOUR_URL";
const supabaseKey = "YOUR_ANON_KEY";
```

4. Open `index.html` in your browser
   OR use a live server

---

## 🔐 Security Notes

* Only the **anon public key** is used in frontend
* No write operations are exposed
* Data is read-only for safety
